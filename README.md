# Metodi Formali
 
Esercizi e dimostrazioni del corso di Metodi Formali, scritti in [Agda](https://agda.readthedocs.io/): un linguaggio funzionale a tipi dipendenti usato anche come assistente di dimostrazione, basato sulla corrispondenza di Curry-Howard (programmi = dimostrazioni, tipi = proposizioni).
